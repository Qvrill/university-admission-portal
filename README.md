Sistem Informasi dan Pendaftaran Mahasiswa Baru 

Proyek ini adalah aplikasi web portal informasi sekaligus pendaftaran mahasiswa baru untuk Universitas Seoul. Web ini dirancang sebagai jembatan bagi calon mahasiswa untuk mendapatkan informasi lengkap mulai dari berita kampus, rincian biaya, fasilitas, hingga akses langsung ke formulir pendaftaran.

Fitur dan Karakteristik Proyek

Portal Informasi Terpadu: Menyajikan informasi satu pintu mulai dari berita terkini kampus, visualisasi fasilitas akademis, hingga peta lokasi menggunakan integrasi Google Maps.
Interaktivitas Jendela Detail (Pop-up Modal): Menggunakan JavaScript murni agar pengunjung bisa melihat tabel rincian biaya (Sarjana, Pascasarjana, dan Profesi) secara langsung melalui jendela pop-up tanpa perlu berpindah halaman atau memuat ulang (reload) website.
Arsitektur Modular PHP: Menggunakan pemisahan komponen header dan footer secara modular agar kode lebih rapi, mudah dirawat, dan tidak redundan di halaman lain.
Alur Pendaftaran Terintegrasi: Menyediakan navigasi langsung (Call to Action) menuju halaman registrasi untuk calon mahasiswa baru.
